# Iniciação

> Objetivo: definir o escopo inicial do projeto e alinhar os objetivos principais.

## Resumo da fase

A Lavoura Inteligente é uma plataforma de rastreabilidade agrícola e conformidade EUDR.
Ela mantém um status de risco (APROVADO, REVISÃO ou BLOQUEADO) para cada talhão e
responde, na balança da cooperativa, se um lote tem origem rastreável. Na Release 1 (AP2)
o MVP roda em **EC2 com Docker Compose e PostgreSQL**.

## Principais atividades

* Identificar os principais requisitos (funcionais e não funcionais).
* Estimar custos e prazos iniciais.
* Avaliar riscos de alto nível.
* Criar um caso de negócio (business case).
* Produto principal: visão do projeto e caso de negócio aprovado.
